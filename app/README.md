# WB Parser

## Запуск

Установка:

```bash
pip install -r requirements.txt
playwright install
```

Запуск:

```bash
python main.py
```

## Сборка `.exe`

```bash
pip install pyinstaller
pyinstaller --onefile main.py
```

## Возможности

- Playwright
- Прокси
- Cookies
- GUI
- Авторизация
- БД
- Telegram-бот
- Docker
- `.exe`
